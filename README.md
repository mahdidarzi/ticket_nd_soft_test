# Ticket Support API

A RESTful microservice for managing support tickets, built with Spring Boot.

## Tech Stack

- **Java 17**
- **Spring Boot 3.3.2**
- **Spring Data JPA (Hibernate)**
- **H2 Database** (file-based)
- **Lombok**
- **Spring AOP** (custom execution time logging)
- **SpringDoc OpenAPI (Swagger UI)**
- **Jakarta Bean Validation**

---

## Prerequisites

- JDK 17 or later
- Maven 3.8+
